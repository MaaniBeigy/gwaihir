Field semantics and defaults:

- "name":
  - A short verb-based description of the main activity (e.g. "wake up", "go to bed", "eat breakfast", "eat lunch", "eat dinner", "work", "commute to work", "play padel", "go running", "read", "visit family").

- "description":
  - Use a concise description derived from the relevant parts of the interview history for that activity (you do NOT need to copy the full raw history).
  - Example: "On weekdays I wake up at 06:30." or "I play padel on Wednesdays 21:00-22:00 and Fridays 20:00-21:30."

- "IsInstantaneous":
  - true if the activity is a momentary action (e.g. "weigh myself", "wake up", "go to bed").
  - false if the activity has a meaningful duration (meals, work, sports, commute, reading).
  - If unclear, set to false.

- "IsRegular":
  - true if the history clearly indicates a repeated pattern (typical day, specific days of week, every weekend, etc.).
  - false if it is a one-time or unspecified occurrence.

- "frequency.type":
  - "daily" for routines that occur every (working) day or "typically every day".
  - "specific_days" for patterns like "Wednesdays and Fridays", "Tuesdays and Thursdays", "on Sunday".
  - "weekly" for "every week" without specified days.
  - "monthly" for "every month".
  - "one_time" if it appears to be a single event without recurrence.

- "frequency.days":
  - Use ["mon","tue","wed","thu","fri","sat","sun"] for specific days when they are clearly mentioned.
  - For "workday" or "typical work/study day" routines (questions 1-7 in interview, covering sleep, eat, and work/study), you may assume ["mon","tue","wed","thu","fri"] unless explicitly stated otherwise.
  - A "workdays" or "Monday-Friday" range always means all five weekdays: list ["mon","tue","wed","thu","fri"] in full. Never reduce such a range to only its endpoints ["mon","fri"]. Likewise "weekend" always means ["sat","sun"].
  - Use null if not applicable or not specified.

- "frequency.count":
  - Number of times per period when clearly specified.
  - Use 1 if the pattern is "every [period]" and no other count is given (for single blocks like "work 07:30–16:00" on typical workdays).
  - For per-day schedules (e.g. wake up daily at 06:30), you may use 1 with type "daily".

- "IsRepetitive":
  - true if the activity repeats itself as a routine (almost all interview-based routines will be true).
  - false otherwise.

- "activity_duration":
  - Total duration of the activity in minutes when specified or clearly inferable:
    - If start and end time are given, compute the difference in minutes.
    - Only include a full "HH:MM-HH:MM" range when the interview explicitly provides exact times.
    - Example: 07:00-07:10 → 10; 12:30-13:00 → 30; 21:00-22:00 → 60; 10:00-14:00 → 240.
  - Must be null if the activity is instantaneous (e.g., waking up, going to bed).
  - If duration cannot be inferred for non-instantaneous activities, use a reasonable estimate or null.

- "IsArbitrary":
  - true if the temporal placement is flexible within the period (not tied to specific days or times).
  - false if the schedule is tied to specific days, times, or clear recurring patterns (most interview routines will be false).
